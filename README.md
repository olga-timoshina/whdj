PROD-03	GET-запрос формы создания товара	Раздел «Товары» открыт	1. Нажать «Добавить товар» / «Создать» 2. Смотреть Network	Статус 200 OK, форма содержит поля (наименование, артикул, единица измерения, цена и т.п.), поле «Наименование» обязательно	High	
PROD-04	POST-запрос создания товара (валидные данные)	Форма создания открыта	1. Заполнить обязательные поля 2. Нажать «Сохранить» 3. Найти POST-запрос	Метод POST, статус 302 (redirect) или 200, товар появляется в списке, счётчик увеличивается на 1	High	
PROD-05	POST-запрос создания товара (пустое наименование)	Форма создания открыта	1. Оставить «Наименование» пустым 2. Нажать «Сохранить»	Статус 200 (возврат формы) или 400, отображается сообщение об ошибке валидации, товар не создаётся	High	
PROD-06	GET-запрос карточки товара (детали)	В списке есть хотя бы один товар	1. Нажать на товар 2. Смотреть Network	Статус 200 OK, URL содержит ID товара (например /products/1/), тело содержит данные товара	Medium	
PROD-07	GET-запрос редактирования товара	Товар существует	1. Открыть товар 2. Нажать «Редактировать» 3. Смотреть Network	Статус 200 OK, форма предзаполнена текущими данными товара	Medium	
PROD-08	POST-запрос обновления товара	Форма редактирования открыта	1. Изменить наименование 2. Нажать «Сохранить»	Метод POST, статус 302/200, изменения отображаются в списке и карточке	Medium	
PROD-09	Удаление товара (POST/DELETE)	Товар существует	1. Нажать «Удалить» 2. Подтвердить 3. Смотреть Network	Запрос удаления (POST или DELETE), статус 302/200, товар исчезает из списка, счётчик уменьшается	Medium	
PROD-10	Проверка заголовков ответа раздела «Товары»	DevTools → Network открыт	1. Открыть раздел 2. Headers → Response Headers	Content-Type text/html	 charset=utf-8, статус 200, нет утечки стектрейсов/внутренних путей	Low

## 1. Цель тестирования

Проверка корректности основных функций системы складского учета:
- работа со справочниками;
- оформление складских операций;
- корректный пересчет остатков;
- запрет отрицательных остатков;
- фиксация операций в журнале движений;
- сохранение целостности данных.
