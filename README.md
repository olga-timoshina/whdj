# 🐛 Bug Report — [UI/UX] Некорректное выравнивание карточек сводки на планшете

| Поле | Значение |
|---|---|
| **ID** | BUG-001 |
| **Тип** | UI/UX |
| **Компонент** | Dashboard |
| **Приоритет** | 🟡 Medium |
| **Серьёзность** | 🟢 Minor |
| **Окружение** | Chrome 130+, Windows 11, разрешение 768×1024 |
| **Автор** | @[ваш-ник] |
| **Дата** | 2026-11-12 |

## 📝 Описание
При разрешении 768px карточки сводки (Товары, Склады, Контрагенты, Документы) выстраиваются в два ряда неравномерно — вторая карточка смещена относительно первой.

## 🔁 Шаги воспроизведения
1. Открыть https://warehouse-django-nmp9.onrender.com/ в Chrome.
2. Открыть DevTools → Device Toolbar.
3. Установить разрешение 768×1024.
4. Прокрутить к блоку сводки.

## ✅ Ожидаемый результат
Карточки выровнены равномерно (2×2 или 1×4), отступы одинаковые.

## ❌ Фактический результат
Вторая карточка смещена вниз и вправо, отступы разные.

## 📎 Вложения
- Скриншот: `../screenshots/tablet-layout.png`
- Лог консоли: ошибок нет

## 📝 Дополнительно
Дефект воспроизводится стабильно, не зависит от браузера.

# 🐛 Bug Report — [Функциональный] Дата документа отображается в неверном формате

| Поле | Значение |
|---|---|
| **ID** | BUG-002 |
| **Тип** | Функциональный |
| **Компонент** | Документы |
| **Приоритет** | 🔴 High |
| **Серьёзность** | 🟠 Major |
| **Окружение** | Chrome 130+, Windows 11 |
| **Автор** | @[ваш-ник] |
| **Дата** | 2026-11-12 |

## 📝 Описание
В таблице «Последние документы» дата отображается как `12.11.2026 11:12`, тогда как по требованиям ожидается формат ISO `2026-11-12 11:12` (или локаль `DD.MM.YYYY`, но без путаницы с MM/DD).

## 🔁 Шаги воспроизведения
1. Открыть https://warehouse-django-nmp9.onrender.com/.
2. Прокрутить к таблице «Последние документы».
3. Посмотреть на колонку «Дата».

## ✅ Ожидаемый результат
Дата в формате, указанном в требованиях (например, `2026-11-12 11:12`).

## ❌ Фактический результат
Дата отображается как `12.11.2026 11:12` — формат не соответствует требованию.

## 1. Цель тестирования

Проверка корректности основных функций системы складского учета:
- работа со справочниками;
- оформление складских операций;
- корректный пересчет остатков;
- запрет отрицательных остатков;
- фиксация операций в журнале движений;
- сохранение целостности данных.
