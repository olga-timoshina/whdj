## 🎯 Цель
Убедиться, что главная страница складской системы корректно загружается и отображает сводные данные по складу без ошибок.

## ✅ Предусловия
- Сайт доступен: https://warehouse-django-nmp9.onrender.com/
- Браузер: Google Chrome (последняя версия)
- Стабильное интернет-соединение
- Учтён «холодный старт» Render (первая загрузка — до 50 сек)

## 🧪 Тестовые данные (ожидаемые значения)

| Сущность | Ожидаемое значение |
|---|---|
| Товары | 1 запись |
| Склады | 1 объект |
| Контрагенты | 1 запись |
| Документы | 1 (проведено: 1) |
| Строк остатков | 1 |
| Суммарный остаток | 27,00 |

## 📋 Шаги выполнения

| # | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть https://warehouse-django-nmp9.onrender.com/ в Chrome | Страница загружается, HTTP 200 |
| 2 | Дождаться полной загрузки (до 50 сек при холодном старте) | Отображается заголовок «Складская система учета» |

| 4 | Проверить блок «Состояние склада» | Строк остатков = 1, Суммарный остаток = 27,00 |
| 5 | Проверить таблицу «Последние документы» | Строка: ID=1, Тип=Приход, Номер=1, Дата=12.11.2026 11:12, Откуда=южный, Куда=южный, Контрагент=южный, Проведен=Да |
| 6 | Открыть DevTools → Console (F12) | Нет критических ошибок (красных сообщений) |
| 7 | Открыть DevTools → Network | Ключевые запросы завершились со статусом 200 |

## 1. Цель тестирования

Проверка корректности основных функций системы складского учета:
- работа со справочниками;
- оформление складских операций;
- корректный пересчет остатков;
- запрет отрицательных остатков;
- фиксация операций в журнале движений;
- сохранение целостности данных.
