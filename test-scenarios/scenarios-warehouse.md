# 🧪 Сценарии тестирования — Складская система учета

---

## SCEN-001 — Просмотр сводки по складу

| Поле | Значение |
|---|---|
| **ID** | SCEN-001 |
| **Приоритет** | 🔴 High |
| **Компоненты** | Dashboard, Остатки |

**Описание:** Пользователь открывает главную страницу и просматривает сводные данные по складу: количество товаров, складов, контрагентов, документов, а также суммарный остаток.

**Ожидаемый результат:** Все цифры соответствуют данным в системе, таблица последних документов отображается корректно.

## SCEN-002 — Работа со справочником товаров

| Поле | Значение |
|---|---|
| **ID** | SCEN-002 |
| **Приоритет** | 🔴 High |
| **Компоненты** | Товары, Склады |

**Описание:** Пользователь переходит в раздел «Товары», просматривает список, при необходимости добавляет новую запись и проверяет её отображение в сводке на главной.

**Ожидаемый результат:** Новая запись появляется в списке и учитывается в сводке.

## SCEN-003 — Просмотр документа движения

| Поле | Значение |
|---|---|
| **ID** | SCEN-003 |
| **Приоритет** | 🟡 Medium |
| **Компоненты** | Документы |

**Описание:** Пользователь открывает раздел «Документы», находит документ «Приход №1» и проверяет его поля: дата, откуда, куда, контрагент, статус проведения.

**Ожидаемый результат:** Все поля документа соответствуют данным, отображаемым на главной странице.

## SCEN-004 — Проверка адаптивности и кросс-браузерности

| Поле | Значение |
|---|---|
| **ID** | SCEN-004 |
| **Приоритет** | 🟡 Medium |
| **Компоненты** | Весь интерфейс |

**Описание:** Пользователь открывает сайт в разных браузерах (Chrome, Firefox, Edge) и на разных разрешениях (375px, 768px, 1440px), проверяя корректность отображения всех блоков.

**Ожидаемый результат:** Интерфейс корректно отображается во всех браузерах и на всех разрешениях, элементы не перекрываются, текст читаем.
